# Talent Forge

Конструктор вымышленных классов в стиле World of Warcraft: Wrath of the Lich King. Редактор работает в браузере; аккаунты и проекты сохраняются сервером в SQLite.

## Запуск

Нужен **Python 3.12 или новее**. Устанавливать зависимости или отдельный сервер базы не требуется.

```sh
git clone https://github.com/sergeraylenyaru/talenttree_creator.git
cd talenttree_creator
python3 server.py
```

Открыть **http://localhost:8000**. На Windows можно использовать `py server.py`.

SQLite автоматически создаётся в `data/talents.sqlite3`. Для резервной копии остановить сервер и скопировать этот файл. База, аккаунты и локальные файлы не входят в Git.

## Возможности

- Новый класс: две ветки, пять рядов, четыре ячейки в ряду.
- До пяти веток; добавление и удаление рядов. Технический предел — 1000 рядов на ветку.
- Названия класса и веток, лимит очков и стоимость открытия рядов.
- Таланты: иконка, название, 1–100 рангов, отдельное описание каждого ранга, зависимость от другого таланта той же ветки. Поддерживаются зависимости в одном ряду, циклы запрещены.
- Калькулятор: левая кнопка добавляет очко, правая или Shift + клик снимает. Проверяются требования рядов, полный ранг предшественника, лимит очков и зависимые таланты.
- Список способностей: название, описание, иконка, ресурс, время применения, перезарядка, дальность, связь с талантом.
- Стартовый каталог иконок с поиском, ввод имени любой WoW-иконки, загрузка PNG/JPEG/WebP до 250 КБ. Это не полный каталог всех иконок игры.
- Импорт десяти стандартных классов 3.3.5a: 829 талантов, 2243 описания рангов, позиции и зависимости. Английские исходные названия и описания; загружается редактируемая копия. Базовые способности не входят в набор.
- Регистрация по логину и паролю, вход, выход, список своих классов, копирование и удаление. Сохраняются дерево, способности и текущее распределение очков.
- Черновик в localStorage, импорт/экспорт JSON. Черновик привязан к браузеру, не к учётной записи.
- Публичная ссылка на снимок класса и билда. Открывается без аккаунта; последующие правки оригинала не меняют снимок. Создание ссылки явно подтверждается в интерфейсе.

## Проверки

Python проверяет HTTP API, регистрацию, вход, хранение паролей, изоляцию проектов, выход, общий доступ и валидацию исходных данных:

```sh
python3 -m unittest discover -s tests -p 'test_*.py'
```

Для проверки калькулятора и всех стандартных деревьев нужен Node.js 22+:

```sh
node --test tests/engine.test.js
```

## Настройка и размещение

Переменные окружения: `PORT` (8000), `HOST` (127.0.0.1), `TALENT_DB` (путь к SQLite), `COOKIE_SECURE=1` (Secure-cookie для HTTPS). Их нужно устанавливать средствами системы/хостинга; `.env` автоматически не читается.

Это первая локальная версия. Сервер стандартной библиотеки Python предназначен для разработки. Для публичной эксплуатации нужны поддерживаемый сервер приложения или перенос API на подходящий фреймворк, HTTPS, постоянный диск для SQLite и резервные копии. GitHub Pages не запускает Python и не обеспечивает аккаунты/сохранение. Не размещайте файл базы в статической папке `static/`.

Ограничение первой версии: у класса хранится одно текущее распределение очков; отдельные варианты можно сохранить копиями класса, экспортировать или передать ссылками-снимками. Способности имеют одно описание и набор характеристик; отдельные ранги способностей и русский перевод стандартных талантов пока не реализованы. Боевые эффекты не исполняются и не симулируются.
