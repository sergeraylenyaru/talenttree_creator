# Источники

## Стандартные таланты 3.3.5a

Данные преобразованы из [CraftedRO/Offline-talent-calculator-for-WotLK-3.3.5a](https://github.com/CraftedRO/Offline-talent-calculator-for-WotLK-3.3.5a), файлы `talents/<Class>/data.js`. В исходном проекте указана GNU GPL v3; её полный текст сохранён в [licenses/wotlk-data-GPL-3.0.txt](licenses/wotlk-data-GPL-3.0.txt). Производные данные в `static/presets/*.json` распространяются с сохранением этой лицензии и указания источника. SHA исходного файла каждого класса записан в поле `source.dataBlob`.

Сохранены расположение, максимальные ранги, полные тексты рангов и зависимости. HTML-разметка описаний преобразована в обычный текст. Исправлено только соответствие имени иконки `Judgements of the Wise` файлу `judgementofthewise.jpg`. Проверки сверяют число рангов, уникальность ячеек и идентификаторов, наличие иконок в исходном списке файлов, корректность и отсутствие циклов зависимостей. Это не независимая сверка всех числовых эффектов с клиентом Blizzard.

Иконки стандартных талантов загружаются из исходного репозитория по HTTPS. Остальные WoW-иконки загружаются с `https://wow.zamimg.com/images/wow/icons/large/<name>.jpg`. Доступность сторонних изображений не гарантируется; при ошибке дерево остаётся рабочим. Изображения не включены в локальный архив. Загрузка собственных иконок отключена; доступны изображения из каталога.

World of Warcraft, игровые названия и изображения принадлежат соответствующим правообладателям, включая Blizzard Entertainment. Лицензия исходного программного проекта сама по себе не предоставляет отдельные права на игровые изображения.

## TBC 2.4.3

Наборы для девяти классов (579 талантов) преобразованы из XML игровых данных проекта [Vampyr7878/WoW-Talent-Caluclator-TBC](https://github.com/Vampyr7878/WoW-Talent-Caluclator-TBC), `WoW Talent Calculator TBC/Data/*.xml`. Сохранены все ячейки, ранги и зависимости по имени. Пустые ячейки не становятся талантами. Лимит — 61 очко, девять рядов. Использованы игровые данные, программный код исходного приложения не включён. Независимая полная сверка числовых эффектов с клиентом 2.4.3 не проводилась.

## Forever

Данные 468 обычных талантов девяти классов и изображения взяты из [MAF2414/wow-forever-talents](https://github.com/MAF2414/wow-forever-talents), встроенный объект DATA в `docs/index.html`. Исходный снимок: клиент **1.60.1.69876, 16 сентября 2026**, таблицы Wago.Tools. Это данные того же режима Forever, который представлен по адресу `https://www.wowhead.com/forever/ru/talent-calc/druid`, но не копия текущей русской страницы Wowhead. Названия и описания английские, возможны расхождения по обновлениям.

Импортированы 27 обычных веток с 51 очком и семью рядами. Три узла вне обычной сетки не импортированы. Единственная дополнительная обратная связь охотника, помеченная источником как некорректная, исключена; обычная зависимость сохранена. Исходные примечания доступны в `source.notes` JSON каждого класса. Число рангов, размещение, обычные зависимости проверены автоматически. Изображения Forever встроены как исходные JPEG data URI; код просмотрщика не включён. Данные и изображения игры принадлежат Blizzard; GPL-файл предыдущего набора не является лицензией на эти материалы.

`static/icon-catalog.json` объединяет изображения всех 28 импортируемых классов с поисковыми названиями талантов, веток и классов. Это каталог используемых талантами изображений, а не полный архив всех иконок клиента.

## Cataclysm 4.3.4

Десять наборов (597 талантов, 30 веток) преобразованы из `src/editions/cata.json` проекта [fooxytv/cplus-talents](https://github.com/fooxytv/cplus-talents/blob/main/src/editions/cata.json), исходный Git blob `a6ce40095cb8ca84926e81bca6c70db88a0f6bfa`, снимок 21 сентября 2026. Этот набор собран из данных калькулятора Wowhead. Сохранены ячейки, ранги, описания и зависимости; лимит — 41 очко, семь рядов, пять очков на ряд. В Arcane у мага сохранён 21 именованный талант: исходный набор исключает одну устаревшую безымянную запись, которая перекрывает Improved Arcane Explosion.

Способности основной ветки взяты отдельно из клиентских таблиц **4.3.4.15595** проекта [caicaicai/dbc434](https://github.com/caicaicai/dbc434). `TalentTreePrimarySpells.dbc` задаёт 89 связей «ветка → выдаваемая способность»; `TalentTab.dbc` добавляет 31 способность искусности, включая две у Feral Combat. Всего 120 записей, распределённых по веткам. Искусность помечена требованием 80-го уровня; набор рассчитан на максимальный уровень 85. Названия/иконки/базовые параметры/описания берутся из Spell и связанных таблиц. Форматы сверены с [wowdev/WoWDBDefs](https://github.com/wowdev/WoWDBDefs).

Проверяемые Git blob таблиц: `TalentTreePrimarySpells.dbc` — `c57810a4e2a450f12aed4529629652b2cf282112`; `TalentTab.dbc` — `7dc9897d9edf8d3e195aa6c793ce0e0492811fce`; `Spell.dbc` — `c4f14b1d25bfb68745b5e15d35ad4e85904cc4d0`; `SpellEffect.dbc` — `15203d5ac3cd4cbeba3319276f5a8ef426d4f423`.

Описания специализаций содержат базовые клиентские значения, без симуляции экипировки, рейтингов, аур и всех модификаторов. Формулы с зависимостью от характеристик обозначены символически; это не обещание совпадения численного урона с персонажем в игре. Глифы и талантовые модификаторы в таких подсказках не применяются. Независимая полная сверка всех эффектов с игровым клиентом не проводилась. Игровые данные принадлежат Blizzard; программный код сторонних калькуляторов не включён.

Для пересборки: `python3 tools/build_cata_presets.py` из корня проекта. Входы: исходный JSON в `work/cata-source.json`, таблицы DBC в `work/sources/dbc434/`; используются TalentTab, TalentTreePrimarySpells, Spell, SpellIcon, SpellEffect, SpellDuration, SpellCastTimes, SpellCooldowns, SpellPower, SpellRange, SpellAuraOptions, SpellDescriptionVariables, SpellRadius и SpellRuneCost. Сами большие клиентские таблицы не входят в репозиторий.

## Каталог современных иконок WoW

`static/retail-icons.json` содержит **33 765** записей из текущего списка `parts/interface.csv` проекта [wowdev/wow-listfile](https://github.com/wowdev/wow-listfile/blob/master/parts/interface.csv), снимок 8 ноября 2026, Git blob `c3c322ee9915eb86784bb70b2253b82ab29a93cb`. Выбраны все имена `Interface/ICONS/*.blp`, включая старые и современные наборы, а не только изображения талантов. Это общий список файлов, он не ограничен одной установленной сборкой игры.

Для 440 имён с пробелами/дефисами/другими символами используются идентификаторы `retail:<FileDataID>` и локальная таблица соответствий. Поиск использует имя файла; оружие и доспехи участвуют в прежних фильтрах. Каталог загружается с сервера TalentForge, изображения — с прежнего Wowhead CDN. Сами картинки не копируются. Наличие имени в community listfile не является независимой проверкой его доступности на CDN.

Пересборка: положить исходный CSV в `work/sources/retail-interface.csv`, запустить `python3 tools/build_retail_catalog.py`; скрипт проверяет SHA исходного файла. Выбор открывается в отдельном большом окне: непрерывная прокрутка и поиск охватывают полный каталог; виртуализация отрисовывает только видимую область и небольшой запас строк.
