# Проверка способностей Task 14

Проверены 38 стандартных наборов и 2473 узла талантов. Все 120 записей библиотеки пришли из десяти наборов Cataclysm 4.3.4. В наборах WotLK 3.3.5a, TBC 2.4.3 и Forever сохранены исходные таланты. Эти наборы не поставляют записи боевых способностей. Описание таланта само по себе не запускает заклинание. Каждый такой узел можно открыть в редакторе и связать с новой или существующей записью.

Из стандартного каталога проверены ID, наличие данных применения и затрат, ссылки, выбранная цель, доставка и категория игровых эффектов. CSV со всеми 120 записями строится командой `node tools/audit-abilities.mjs`. Состояние в CSV означает готовность конфигурации. Сценарии испытаний движка и Chromium проверяются отдельно. Личные классы в других браузерах и локальные базы Windows находятся вне проверенного каталога.

До исправления все 120 записей поставлялись как метаданные. Четыре из них уже тогда описывали питомцев или удар по дополнительному противнику. После исправления 11 активных записей получили исполняемый эффект и четыре пассивные записи получили школьный множитель. Авторские значения и ранги можно редактировать в мастерской.

## Исправления связей

| Путь | До | После |
| --- | --- | --- |
| Две записи библиотеки с одинаковыми данными | Синхронизация могла схлопнуть их в один ID | Синхронизация обновляет отображение узла и сохраняет оба ID |
| Старое обратное поле `talentId` и узлы `grantedAbilityId` | Явное обратное поле могло скрыть другие способы открытия | Поддерживаются все действующие ссылки, включая масштабирование от ранга |
| Замена способности в узле | Требовалось обходить через ячейку и редактор размещения | Сохраняется ID узла, зависимость и допустимый ранг билда. Старая запись остаётся в библиотеке |
| Создание способности из узла | Способность могла сохраниться до подтверждения связи | Сохранение из мастерской создаёт запись и размещение вместе |
| Потерянная запись в старом документе | Синхронизация блокировала открытие | Старую копию можно открыть и заменить ссылку. Обычная проверка новых документов требует действующей ссылки |
| Панель после изучения таланта | Старые сохранённые ячейки могли скрыть новую способность | Новая настроенная способность занимает пустую ячейку или ячейку тренировочного примера, если место есть |
| Запись без эффектов | Нажатие могло расходовать ресурс и запускать перезарядку | Применение отклоняется до списания |
| Редактирование способности специализации | Способ открытия мог сброситься до общего | Неизменённый выбор специализации и ветки сохраняется |

Существующие стандартные способности Cataclysm открываются специализацией. Назначать им произвольные узлы талантов не требуется. Для записи с известным исходным ID и без авторских параметров при загрузке подставляются проверенные эффекты. Пустой массив эффектов, собственное оформление и параметры мастерской сохраняют приоритет.

## Что проверить и какие шаблоны выбрать

- **Активные записи для ручной настройки** — Starsurge, Mangle, Swiftmend, Explosive Shot, Holy Shock, Templar's Verdict, Penance, Holy Word: Chastise, Mutilate, Shadowstep, Lava Lash, Earth Shield, Conflagrate, Bloodthirst и Shield Slam. Точный перечень с версиями, ID и затратами дан в CSV.
- **Шаблоны для настройки** — быстрый или тяжёлый удар для оружейных атак, снаряд для прямой дальней атаки, «Горение» для периодической, «Тайный луч» для канала, «Свет исцеления» или «Восстановление» для цели на себя. Для собственных защитных и ресурсных способностей доступны «Поглощение» и «Всплеск ресурса». Это стартовые конфигурации. Они требуют согласовать школу, величину, условия и затраты с назначением способности.
- **Пассивные записи** без боевого поведения настраиваются через постоянный эффект на героя, бонус либо существующий триггер в разделе персонажа. В CSV 86 пассивных записей требуют такой настройки.
- **Активные записи за пределами текущих механик** — Intimidation, Summon Water Elemental, Summon Felguard и Blade Flurry. Они требуют питомца, призыва или второго противника. Их записи видны с предупреждением.
- **Частично восстановленные** перечислены в CSV. Например, у Avenger's Shield работает урон по манекену, а отскок и прерывание требуют других целей или механик. Aimed Shot использует экипированное дальнее оружие. У Mind Flay три тика, а манекен остаётся неподвижным. Интервалы Pyroblast и Unstable Affliction распределяют указанный суммарный DoT на четыре и пять тиков соответственно.

Предпросмотр запускается в отдельной сессии. Можно выбрать клип реальной GLB-модели, проверить снаряд и журнал, а для щита вызвать контролируемый удар манекена. Дружественной целью служит герой. Автоматическое срабатывание относится к существующим пассивным триггерам и экипировке, активные способности запускает игрок.
