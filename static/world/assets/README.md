# Локальные модели для тренировочной площадки

После `npm ci` собери браузерный модуль командой `npm run build:world` из корня репозитория. Без своего экспорта 3D работает с оригинальным процедурным персонажем Talent Forge.

## Подключение экспорта из WoW

1. Открой [официальный репозиторий wow.export](https://github.com/Kruithne/wow.export) и установи приложение по ссылке из раздела Installing.
2. Выбери установленный локальный клиент игры. В браузере моделей или персонажей найди подходящий игровой облик и проверь его в 3D-просмотре.
3. Выбери экспорт **GLB** или **glTF**. Включи экспорт текстур и **Export Animations**, если они доступны для выбранного персонажа. У GLB ресурсы могут быть упакованы в один файл. У glTF сохрани его `.bin` и изображения вместе с моделью в исходной относительной структуре.
4. Создай в корне репозитория `local-assets/wow/character/` и скопируй туда экспорт.
5. Скопируй [manifest.example.json](manifest.example.json) в `local-assets/wow/manifest.json`. Укажи точное имя файла и клипов. Имена чувствительны к регистру. Для glTF список `animations[].name` можно посмотреть в JSON. Для GLB проверь список действий в Blender или другом glTF-просмотрщике.
6. Запусти локальный сервер и открой [http://localhost:8000](http://localhost:8000). Пример для Windows PowerShell из корня проекта:

   ```powershell
   $env:TALENT_LOCAL_WOW_ASSETS = "1"
   $env:HOST = "127.0.0.1"
   python server.py
   ```

7. Открой площадку заново. Метка **Локальная модель** подтверждает загрузку. Проверь стойку, ходьбу, бег и прыжок. Если персонаж визуально идёт боком или назад, выставь `rotation` по таблице ниже. Сверь масштаб модели и высоту стоп в стойке.

## Формат манифеста

| Поле | Назначение |
| --- | --- |
| `model` | Относительный путь внутри `character/` к `.glb` или `.gltf` |
| `scale` | Равномерный масштаб модели (по умолчанию 1) |
| `rotation` | Визуальный поворот модели вокруг +Y по правилу правой руки, в градусах (по умолчанию 0) |
| `heightOffset` | Дополнительное смещение после автоматического выравнивания. Плюс поднимает модель, минус опускает (по умолчанию 0) |
| `animations` | Сопоставление состояний `idle`, `walk`, `run`, `jump`, `fall` с именами клипов. `attacks` зарезервирован |

В Talent Forge +Y направлена вверх, а локальная ось вперёд у контроллера — −Z. Манифест поворачивает только визуальную модель. При нулевом угле орбиты камера смотрит по −Z, вправо для неё +X. На любом угле W следует горизонтальному направлению взгляда, D — направлению вправо относительно камеры.

| Исходное направление лица модели в glTF | `rotation` |
| --- | --- |
| −Z | 0 |
| +X | 90 |
| +Z | 180 |
| −X | −90 |

Загрузчик измеряет нижнюю границу геометрии в исходной позе после масштаба и поворота, включая вложенные группы и скиннинг. Эта граница совмещается с полом, после чего применяется `heightOffset`. Корень движения и клипы glTF сохраняют свои независимые преобразования. Если в прежнем манифесте `heightOffset` компенсировал высокий pivot, начни с 0. Для экспортов с необычной исходной позой проверь результат в стойке.

Загрузчик читает glTF 2.0 и GLB с мешами, обычными материалами, PNG/JPEG/WebP, скелетами, скиннингом и клипами. Дополнительные декодеры Draco, Meshopt и KTX2 не подключены. Клип должен принадлежать скелету модели и желательно быть без перемещения корневого узла, поскольку перемещение уже выполняет контроллер. Повторное использование анимаций с других скелетов требует отдельного ретаргетинга.

При отсутствии отдельных клипов используются совместимые запасные состояния (например, Walk для Run). Модель без клипов перемещается без поз. Если экспорт не подходит, убери манифест и открой арену заново, чтобы использовать анимированный учебный персонаж. Ошибка загрузки также оставляет учебного персонажа на сцене и показывает причину.

Каталог `local-assets/wow/` игнорируется Git. Экспортированные файлы остаются на компьютере пользователя и не входят в репозиторий, сборку или публикации. Сервер раздаёт их только после явного включения, при локальном привязывании и прямом запросе к loopback-адресу.

## Окружение, манекен и оружие / Environment, target and weapon

Дополнительные каталоги `world/`, `targets/` и `weapons/` используют тот же локальный маршрут и те же ограничения. Расширенный манифест сохраняет существующие поля персонажа. Пример точных имён файлов и порядок измерения пола, стен и кости оружия приведены в [руководстве RU / EN](../../../docs/local-arena.md).
